# Задание 1

## Задача 1

### Текст задачи

Сформировать список из названий функций модуля List.

### Алгоритм решения

Сначала программа загружает сборку (assembly), в которой находится тип List<int>, затем из этой сборки извлекает тип модуля List по его полному имени "Microsoft.FSharp.Collections.ListModule". Далее с помощью метода GetMethods() получает массив всех методов, определённых в этом модуле. После этого каждый метод преобразуется в его имя через Array.map, затем удаляются возможные дубликаты, возникающие из-за перегруженных версий функций, с помощью Array.distinct. Полученные названия сортируются по алфавиту через Array.sort и преобразуются в список с помощью Array.toList. В функции main этот список выводится построчно, затем выводится общее количество функций, и программа ожидает нажатия любой клавиши перед завершением.

## Задача 2

### Текст задачи

Возвратить true, если число состоит только из чётных цифр, и false — в противном случае

### Алгоритм решения

Основная логика сосредоточена в функции checkEvenDigits, где первым делом прописано условие выхода: если число n становится равным нулю, это означает, что все предыдущие цифры успешно прошли проверку, и функция возвращает true. На каждом шаге рекурсии программа выделяет последнюю цифру числа с помощью операции взятия остатка от деления на десять (n % 10), после чего проверяет её на нечетность, остаток от деления на два не равен нулю. Если цифра оказывается нечетной, функция немедленно прекращает работу и возвращает false. Если же цифра четная, функция вызывает саму себя, передавая в качестве аргумента оставшуюся часть числа без последней цифры, которая отсекается с помощью целочисленного деления на десять (n / 10). В блоке main программа запрашивает у пользователя ввод, считывает его как строку через Console.ReadLine, преобразует в целое число с помощью int и выводит итоговый логический результат, где спецификатор %d отвечает за отображение самого числа, а %b — за текстовое представление результата true или false.

## Задача 3 

### Текст задачи 
Опишите функции, осуществляющие основные математические операции над комплексными числами (сложение, вычитание, умножение, деление, возведение в степень). Использовать готовый класс Complex запрещено.

### Алгоритм решения 

Определение структуры (type MyComplex): Для начала я создал собственный тип данных. Это позволило объединить два дробных значения (вещественную часть Re и мнимую Im) в один объект. Теперь программа понимает комплексное число как единое целое, а не как набор отдельных цифр. Реализация математических операций: Я описал основные функции для работы с числами: Сложение и вычитание: Просто суммируем или вычитаем части Re и Im по отдельности. Умножение: Здесь используется формула раскрытия скобок , где учитывается, что (поэтому в вещественной части стоит минус). Деление: Чтобы избавиться от мнимости в знаменателе, я ввел промежуточное значение denom (знаменатель). Также добавлена проверка: если он равен нулю, программа выводит ошибку, а не «падает». Степень: Использована формула Муавра. Число переводится в полярные координаты (через модуль и угол), возводится в степень и возвращается обратно в формат . Функция main (ввод и вывод): Ввод: Программа по очереди запрашивает у пользователя части для двух комплексных чисел и значение степени. Все данные преобразуются из текста в формат float. Обработка: Создаются два объекта z1 и z2, которые передаются в математические функции. Вывод: Для отображения используется вспомогательная функция toString, которая красиво форматирует числа до двух знаков после запятой и добавляет букву i.
